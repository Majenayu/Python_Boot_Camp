# Security policy

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Use GitHub's
private vulnerability reporting flow when available, or contact the maintainer
privately through GitHub with the affected path, reproduction steps, impact,
and mitigation.

Do not include student records, credentials, tokens, or other sensitive data.
Redact all examples before submitting a report.

This educational prototype requires an independent review of authentication,
authorization, and data handling before production use.
